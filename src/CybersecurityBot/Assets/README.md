# Voice greeting asset

`welcome.wav` is the startup WAV played by `VoiceGreeting` using `System.Media.SoundPlayer`.

It is a valid Windows audio placeholder so the playback feature can be demonstrated. Before submission, replace it with your own short recorded spoken greeting (for example: “Hello! Welcome to the Cybersecurity Awareness Bot. I’m here to help you stay safe online.”), while keeping the same file name and WAV format.
